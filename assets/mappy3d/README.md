# Mappy 3D — исходники

Готовые файлы для сайта лежат в `static/3d/` (`mappy3d.js`, `mappy.glb`) и `static/js/mappy3d_boot.js`.
Эта папка нужна, только чтобы менять самого мишку.

- `build.py` — модель в Blender: тело, лапы, лицо, одежда, скелет, веса, мимика.
- `anim.py` — анимации и экспорт в GLB.
- `mappy.src.js` — исходник компонента: слежение за курсором, нажатия, реакции, настроения, фразы.
- `render.py`, `capture.mjs`, `sheet.mjs`, `press.mjs`, `demo.html`, `preview.html` — проверка: рендеры, лист поз, видео, тест нажатий.

## Пересборка
```
pip install bpy                                   # Blender как модуль Python
python3 build.py && python3 anim.py               # пути внутри: /home/claude/mappy3d/ — поменять на свои
npx @gltf-transform/cli optimize mappy.glb ../../static/3d/mappy.glb --compress meshopt --texture-compress false --simplify false --palette false --join false --flatten false
npx esbuild mappy.src.js --bundle --minify --format=esm --target=es2020 --outfile=../../static/3d/mappy3d.js   # нужен пакет three@0.187
```

## Как он стоит на сайте
В любой блок с атрибутом `data-mappy3d="<настроение>"` загрузчик `mappy3d_boot.js` подставляет 3D-мишку.
Картинка внутри блока с `data-mappy-fallback` остаётся, пока 3D не готов, и навсегда — без WebGL, в режиме экономии трафика и в блоках уже 90px.

| Где | Шаблон | Настроение |
|---|---|---|
| Главная, рядом с подсказкой | `includes/mappy_helper.html` | `welcome` — машет; говорит в пузырь подсказок |
| Пустой поиск в каталоге | `catalog/place_list.html` | `empty` — грустит, после нажатия веселеет |
| «Отправлено на проверку» | `base.html` (flash `mappy-submitted`) | `success` — прыгает от радости |
| «Страница недоступна» | `pages/public_unavailable.html` | `lost` — с любопытством осматривается |

Атрибуты блока: `data-bleed="верх право низ лево"` — насколько холст выходит за блок (доли размера блока); `data-min-size` — минимальная ширина для 3D; `data-sleep` — через сколько секунд засыпает.
Из кода страницы мишка доступен как `элемент.mappy` (API в `mappy.src.js`: `touch`, `react`, `express`, `play`, `say`, `on`).

## Главная: облачко и первый кадр

Главная использует 3d/mappy-idle.png — прозрачный кадр этой же GLB-модели. Он виден сразу и остаётся при ошибке WebGL/загрузки или экономии трафика. Старые 2D-позы больше не используются как заставка в подключённых 3D-сценах. Размер резервной картинки и контейнера сохраняется при запуске canvas.

Облачко главной находится над плечом; это доступная кнопка следующей подсказки. Событие mappy:say отменяет отложенную смену текста и заново отсчитывает интервал подсказок, чтобы реплика Маппи не перезаписывалась. На телефоне контейнер 128–164 px и проходит минимальный порог запуска 3D.
