# KidsMap — Google-карта, пины и кластеры

## Текущее состояние кода (2026-11-05, перепроверить перед работой)

- `static/js/google_maps_markers.js` — обёртка: AdvancedMarkerElement при наличии `mapId`, иначе legacy `google.maps.Marker`. Содержимое маркера — `<img>` с data-URL SVG.
- `static/js/home_map.js` (~2250 строк) и `static/js/catalog_map.js` (~1230 строк) — две почти одинаковые реализации: SVG пина, SVG кластера, MarkerClusterer + SuperClusterAlgorithm({maxZoom:18, radius:100}), обработчик клика по кластеру. Плюс Leaflet/OSM-фолбэк.
- `static/js/google_maps_motion.js` — анимации появления/раскрытия кластеров.
- `rebuildMarkers()` удаляет все маркеры и создаёт заново при каждом обновлении.
- Пин: капля 38×48, заливка `category_color_text`, круг `category_color_bg`, глиф категории из `CATEGORY_SVGS` (инлайн в JS — дублирует `static/icons/categories`).

## Целевая архитектура

1. Один общий модуль маркеров/кластеров (например `static/js/kidsmap_map_core.js`), который используют главная и каталог. Различия — через options, не через копию кода.
2. Пин — HTML-элемент внутри AdvancedMarkerElement, стилизуемый CSS-классами (`.km-pin`, `.km-pin--hover`, `.km-pin--selected`, `.km-pin--visited`). Legacy Marker — только фолбэк, когда нет mapId; визуально максимально близко.
3. Глифы категорий — из тех же SVG, что в `static/icons/categories` (единый источник), а не отдельная копия в JS.
4. Обновление маркеров — diff по ключу места: удалить исчезнувшие, добавить новые, не трогать оставшиеся. Ноль мерцания при панорамировании и смене фильтра.

## Пин — визуал

- Форма: мягкая капля с белой обводкой 2px и цветной тенью категории (не чёрной). Внутри — круг-«медальон» с иконкой категории.
- Размер: 40×50 desktop, не меньше 36×46 на мобильном; область касания ≥ 44×44 (невидимый padding).
- Состояния:
  - default — как описано;
  - hover / focus (клавиатура!) — подъём на 4px + scale 1.08, тень плотнее, `--dur-fast`, `--ease-spring`;
  - selected — scale 1.2, белый «ореол»-кольцо, z-index выше всех, под пином подпись-pill с названием (Chiron, обрезка в 1 строку);
  - visited (место уже открывали в этой сессии) — приглушённая насыщенность, маленькая галочка;
  - «открыто сейчас» — опционально маленькая зелёная точка `--brand-jungle` на медальоне (только если backend даёт статус).
- Появление: падение сверху 8px + fade, лёгкий stagger 20–30мс по порядку, суммарно ≤ 400мс; без анимации при повторном показе того же пина.
- Нет emoji, нет стандартного красного пина Google.

## Кластер — визуал

- Круглый «пузырь» цвета бренда с белым числом (Chiron, tabular-nums) и полупрозрачным внешним кольцом.
- 3 размера по количеству: < 10 — 44px, 10–49 — 54px, ≥ 50 — 64px. Цвет можно смещать от `--brand-celadon`-кольца к `--brand-turf` по мере роста.
- Если все точки кластера одной категории — кольцо цвета категории и мини-иконка категории. Смешанный кластер — до 3 маленьких цветных точек категорий на кольце (сегменты), не больше.
- hover — scale 1.06; клик — см. логику.
- Число ≥ 100 → «99+».

## Логика

- Клик по кластеру: если точки разнесены — `fitBounds` по границам точек кластера с padding (учесть высоту bottom sheet / боковой панели). Если точки совпадают или максимальный зум достигнут — показать список мест (choice popover/sheet), а не зумить бесконечно.
- Запросы данных по viewport: на событие `idle`, с debounce ~250мс, отмена предыдущего запроса (AbortController), без дублей.
- Не делать автоматический `fitBounds` после того, как пользователь сам двигал карту (флаг `userInteracted` уже есть — соблюдать).
- Синхронизация список ↔ карта: hover/focus карточки → hover-состояние пина (и раскрытие кластера не нужно — подсветить кластер, содержащий место); клик по пину → прокрутка списка к карточке / открытие карточки.
- Мобильный: выбранное место открывается в bottom sheet (свайп вниз — закрыть), карта не перекрывается попапом. На десктопе — карточка-попап рядом с пином, не перекрывающая сам пин.
- Пустая область: дружелюбное пустое состояние «Здесь пока нет мест» + кнопка «Показать всё / уменьшить масштаб».
- Геолокация: обработать отказ, таймаут, ошибку; кнопка «рядом со мной» с состоянием загрузки.
- Стиль карты — через Map ID (Cloud styling) в Google Console: приглушённые POI и бизнес-метки, пастельная вода/парки, чтобы пины были главными. Стиль описать в `docs/` (какие слои скрыты), т.к. он не в репозитории.

## Доступность

- У пина `title` / aria-label «<Название>, <категория>»; пины доступны с клавиатуры (AdvancedMarker с `gmpClickable`), видимый focus.
- Кластер: aria-label «N мест, нажмите чтобы приблизить».

## Проверка (обязательно)

1. Playwright: главная и каталог на 375×812 и 1440×900 — скриншоты карты с пинами и кластерами.
2. Hover, selected, клик по кластеру (раскрывается / показывает список), закрытие карточки.
3. Смена фильтра — пины не мигают (сравнить число создаваемых маркеров до/после).
4. 500+ точек — панорамирование без лагов (Performance trace, нет long tasks > 100мс при pan).
5. Console без ошибок и без предупреждений Google Maps (deprecated Marker допустим только в фолбэке).
6. Фолбэк без mapId и Leaflet-фолбэк не сломаны.
