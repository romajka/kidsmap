# KidsMap — анимации и микровзаимодействия

## Токены (static/css/motion.css)

| Токен | Значение | Для чего |
|---|---|---|
| `--dur-fast` | 160ms | hover, press, смена цвета, тултипы |
| `--dur-base` | 260ms | раскрытие блоков, появление карточек, модалки |
| `--dur-slow` | 420ms | переходы страниц, hero, большие панели |
| `--ease-out-quint` | cubic-bezier(.22,1,.36,1) | по умолчанию для появления и движения |
| `--ease-spring` | cubic-bezier(.34,1.56,.64,1) | «игривые» моменты: лайк, пин, бейдж, успех |

Сейчас в CSS ещё ~6 разных cubic-bezier и ~8 разных длительностей — новые не добавлять, при правке заменять на токены.

## Каталог паттернов

- Кнопка: hover — фон темнее + подъём 1px; active — `scale(.97)` за `--dur-fast`; primary получает `--btn-shadow` → `--btn-shadow-press`.
- Карточка места: hover — подъём 4px, тень плотнее, фото `scale(1.04)` внутри `overflow:hidden`; не анимировать height/width.
- Лайк/избранное: `--ease-spring` scale 1→1.25→1, заполнение цветом + короткий всплеск частиц (CSS, 6–8 точек, ≤ 500мс). Это ключевой «радостный» момент — делать качественно.
- Чипсы фильтров: выбор — заливка цветом + галочка выезжает слева; счётчик результатов пересчитывается с анимацией числа (≤ 300мс).
- Появление списков: stagger 30–40мс на элемент, максимум ~8 элементов в каскаде, остальные сразу.
- Скелетоны: мягкий shimmer на тинте `--tint-turf-050`, не серый.
- Успех формы («место добавлено»): Mappy + короткая анимация (галочка рисуется stroke-dashoffset), не конфетти на весь экран.
- Переходы страниц: View Transitions (уже есть в motion.css) — сохранять.
- Скролл-появление секций (`scroll_animations.js`): только opacity + translateY ≤ 16px, один раз.

## Правила

- Анимировать только `transform`, `opacity` (и `filter` точечно). Никогда width/height/top/left/margin в цикле.
- Бесконечные анимации — только для индикаторов загрузки и одного-двух декоративных акцентов в hero; не на карточках и не на карте.
- Никаких анимированных `blur()`/`backdrop-filter` (см. раздел Performance в motion.css — они уже выключены по причине производительности).
- Уважать `prefers-reduced-motion`: глобальный guard в motion.css; JS-анимации (Web Animations API, маркеры карты) должны проверять `matchMedia('(prefers-reduced-motion: reduce)')` сами.
- Анимация не должна задерживать действие: навигация, отправка формы, открытие карточки происходят сразу, анимация — параллельно.
- Прерываемость: повторный hover/клик во время анимации не ломает состояние (использовать transitions, а не keyframes, для обратимых состояний).
