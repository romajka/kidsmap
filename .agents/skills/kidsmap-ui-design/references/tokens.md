## Запрещено в новом коде

Нейтрали Tailwind (холодные, синие): `#0f172a #1e293b #334155 #475569 #64748b #94a3b8 #cbd5e1 #e2e8f0 #f1f5f9 #f8fafc`, «emerald»: `#10b981 #059669`, а также почти-бренды `#0D8A52 #009a4e #0b6f39 #00783c`, если для роли есть токен.
Проверка: `grep -nE "#(0f172a|1e293b|334155|475569|64748b|94a3b8|cbd5e1|e2e8f0|f1f5f9|f8fafc|10b981|059669)" <файл>` — для изменённых файлов результат должен уменьшаться, не расти.

## Радиусы

Сейчас в CSS ~10 разных значений (8/10/12/14/16/18/20/22/24/999). Целевая шкала — использовать только:
- 8px — мелкие элементы (теги в таблицах, админка);
- 12px — inputs, кнопки обычного размера;
- 16px — карточки места, панели;
- 24px — крупные блоки, hero, bottom sheet;
- 999px — чипсы фильтров, pill-кнопки, бейджи.
Новое значение вне шкалы — только с объяснением. Если вводишь переменные, называй `--radius-sm/md/lg/xl/pill`.

## Тени

`--shadow` для приподнятых панелей, `--btn-shadow` / `--btn-shadow-press` для primary. Тени тонированы зелёным (rgba(13,73,36,…)) — не использовать чёрные `rgba(0,0,0,…)` тени.

## Motion

`--dur-fast` 160ms, `--dur-base` 260ms, `--dur-slow` 420ms, `--ease-out-quint`, `--ease-spring`. См. `motion.md`.

## !important

В site.css >1000 `!important`. Не добавлять новые; если правило не применяется — найти конфликтующий селектор, а не повышать вес.
