# KidsMap — иконки и иллюстрации

## Семейства (снято 2026-11-05)

| Семейство | Где | Статус |
|---|---|---|
| Material Symbols Rounded (`static/fonts/MaterialSymbolsRounded.woff2`) | ~800 вхождений в шаблонах | ОСНОВНОЕ для UI |
| SVG категорий (`static/icons/categories/*.svg`, 27 шт.) | карточки, фильтры, (должны быть) пины | ОСНОВНОЕ для категорий |
| coolicons (`static/img/icon/coolicons.iconjar`, CSS `--icon-*`) | CSS mask/background | LEGACY — мигрировать |
| Социальные (`static/img/icon/social`) | контакты | Оставить (брендовые лого) |

## Правила

- Material Symbols: одна настройка осей на весь сайт — `font-variation-settings: 'FILL' 0, 'wght' 400, 'GRAD' 0, 'opsz' 24`; активное состояние (выбранный таб, лайк, активный фильтр) — `'FILL' 1`. Не смешивать weight на одной странице.
- Размеры: 18px в плотном тексте/чипсах, 20px в кнопках, 24px в навигации, 32–40px в пустых состояниях (лучше иллюстрация).
- Цвет иконки = `currentColor`; акцентные иконки — `--brand-turf`.
- Иконка рядом с текстом выравнивается по оптическому центру строки (`vertical-align` / flex `align-items:center`), зазор 6–8px.
- Иконка-кнопка без текста: `aria-label`, область касания ≥ 44×44.
- Иконки категорий: один и тот же SVG для категории везде — карточка, фильтр, пин, кластер. Новые категории рисуются в том же стиле (stroke ~2, скругления round, сетка 24).
- Метафоры: настройки — шестерёнка; избранное — сердце (не звезда — звезда занята рейтингом); возраст — «child_care»/«face», не торт; цена — «payments»/«sell», не мешок денег.
- Emoji вместо иконок — запрещено (в т.ч. в кнопках, бейджах, заголовках).

## Иллюстрации

- Главный персонаж — Mappy (`static/js/mappy.js`, `owner_place_mappy.js`): использовать в пустых состояниях, 404, успехе формы, онбординге, загрузке. Не перерисовывать без запроса.
- Если нужен дополнительный набор (icons8 Ouch и т.п.) — один стиль на весь сайт, согласовать с пользователем до внедрения, проверить лицензию.
- Иллюстрация не ставится в продуктовые зоны поиска/карточки — только пустые/переходные состояния и маркетинговые блоки главной.
