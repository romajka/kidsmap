# Промт для Claude Code — редизайн карточки места KidsMap

Скопируй всё, что ниже разделителя, и отправь вместе со ссылкой на макет.

---

Ты работаешь в репозитории KidsMap (Django + Jinja/DTL шаблоны, без сборщика фронтенда).
Задача: перенести в код редизайн страницы карточки места. Макет — по ссылке, которую я приложил
(HTML-макет `Place Card Redesign`, десктоп 1320 px + мобильный кадр 390 px). Макет — источник
визуальной истины; логику и данные бери только из существующего кода.

## Что можно и нельзя

- НЕ менять модели, миграции, вьюхи и контракты API. Все данные уже приходят в контекст.
- НЕ добавлять новых запросов к БД, кроме одного явно разрешённого ниже (его пока нет — значит
  никаких новых запросов).
- НЕ вводить новые цвета. Только токены из `static/css/site.css` (`:root`):
  `--brand-turf: #136f38`, `--brand-celadon: #a8d59b`, `--brand-spruce: #0d4924`,
  `--brand-jet: #1f2933`, `--brand-white: #fcfcfc`. Тинты, которых нет в токенах
  (`#E8F3E5`, `#CDE7C5`, `#F3F9F2`, `#F7FAF7`, `#E3EAE4`, `#EDF1ED`), добавь как новые переменные
  в тот же `:root` — не хардкодь по месту.
- Шрифт остаётся Manrope, иконки — Material Symbols Rounded, как сейчас в проекте.
- Все подписи — через `{% trans %}` / `{% blocktrans %}`, строки завести в `locale/*/LC_MESSAGES/django.po`
  для ru/az/en. Никакого текста в коде без перевода.
- Никаких inline-стилей в шаблонах: макет сделан на inline-стилях по своим техническим причинам,
  в репозитории всё идёт в `static/css/pages/detail.css` по существующим соглашениям имён классов.

## Файлы, которые нужно изменить

- `src/catalog/templates/catalog/place_detail.html` — разметка страницы.
- `static/css/pages/detail.css` — стили и анимации.
- `static/css/site.css` — только добавление токенов тинтов в `:root`.
- `locale/{ru,az,en}/LC_MESSAGES/django.po` — новые строки.
- JS: существующие обработчики (Swiper, избранное, форма отзыва, `data-track-*`) не переписывать —
  подключить к новой разметке, сохранив все атрибуты аналитики.

## Структура страницы (десктоп)

1. Хлебные крошки + кнопка «назад» (40×40), затем `<h1>` с названием. На странице ровно один `<h1>`,
   заголовки секций — `<h2>`.
2. Герой в два столбца: `minmax(0,1fr)` галерея / `424px` панель решения.
   - Галерея: соотношение 4:3, скругление 20 px, стрелки 46×46 по краям, счётчик «1 / 6» справа
     внизу, лента из 6 миниатюр (высота 74 px) под кадром. Swiper остаётся.
   - Панель решения — ОДНА карточка без вложенных рамок: чипы категории/подкатегории, район + метро,
     рейтинг (или «Hələ rəy yoxdur» со ссылкой на форму), кнопка избранного 44×44;
     затем цена крупно (32 px, `--brand-turf`) с подписью «giriş bileti · N tarif», возраст, формат,
     расписание с отметкой «Bu gün açıq», адрес; затем CTA: «Zəng et» (основная, 52 px),
     «WhatsApp» и «Marşrut» (46 px, две колонки); затем описание в 3 строки (`-webkit-line-clamp: 3`)
     и ссылка-якорь «Məkan haqqında».
3. Контент в два столбца: `minmax(0,1fr)` / `372px`.
   - Левая колонка секциями-карточками (белый фон, 1 px `#E3EAE4`, радиус 20 px, паддинг 24 px):
     «Məkan haqqında», «Dəyər və şərtlər», «Cədvəl», «Əsas məlumatlar», «Rəylər», «Xəritədə».
   - Правая колонка `position: sticky; top: 16px`: карточка «Əlaqə» (телефоны, Instagram, сайт, адрес —
     строки по 52 px с иконкой в цветном квадрате 38×38), плашка «Vacib qeyd» с датой добавления,
     блок «Valideynlərlə paylaş» (копирование ссылки, WhatsApp, QR) и рекламный слот с пометкой «Реклама».
4. «Dəyər və şərtlər»: тарифы сгруппированы (Giriş biletləri / Əlavə xidmətlər / Qrup və ekskursiyalar),
   первые 3 строки видны, остальные под кнопкой «Daha N tarif göstər» ↔ «Gizlət» (details/summary или
   существующий JS-тоггл). Дисклеймер про уточнение цены — внизу секции.
5. «Cədvəl»: 7 ячеек-дней в грид, сегодняшний день выделен `--brand-celadon` рамкой и заливкой `#E8F3E5`.

## Секция отзывов — важное

- Два реальных состояния, оба должны работать: пустое («Hələ rəy yoxdur — ilk rəyi siz yazın»)
  и заполненное (средний балл 36 px, гистограмма по 5 звёздам, сортировка, карточки отзывов).
  Переключателя «Boş / Doldurulmuş» в проде быть не должно — это был демо-контрол макета.
- Карточка отзыва: аватар-инициал 44×44, имя, звёзды, дата, текст, кнопки «faydalı / faydasız»
  (высота 40 px) с существующим эндпоинтом голосования, бейдж «Moderasiyada» для непубликованных.
- Форма написания отзыва (существующая, только новый вид):
  - Звёзды 46×46 с живой подписью: 1 → «Çox pis», 2 → «Pis», 3 → «Normaldır», 4 → «Yaxşıdır», 5 → «Mükəmməl!».
  - Чипы-подсказки, которые дописывают текст в textarea (5 штук, dashed-рамка).
  - Textarea `box-sizing: border-box`, min-height 116 px, счётчик «N / 1000» и подсказка
    «Ən azı 20 simvol yazın» → «N simvol daha lazımdır» → «Yaza bilərsiniz — hazırdır».
  - Кнопка отправки заблокирована (фон `#E7EDE7`, `cursor: not-allowed`), пока нет оценки И 20+ символов.
  - Чекбокс «Adımı göstərmə» — если у модели отзыва нет такого поля, НЕ выдумывай его: спроси меня,
    прежде чем добавлять миграцию.
  - Экран благодарности после отправки: «Rəyiniz göndərildi» + пояснение про модерацию.
  - Для гостя вместо формы — блок «Rəy yazmaq üçün hesaba daxil olun» со ссылкой на логин.

## Мобильная версия (≤ 640 px)

Порядок: назад + крошка → `<h1>` → чипы → галерея → карточка «цена / возраст / расписание / адрес» →
«Seçilmiş» + «Marşrut» → «Məkan haqqında» → «Dəyər və şərtlər» → «Rəylər».
- Липкая нижняя панель «Zəng et» + «WhatsApp» (кнопки 52 px), фон `rgba(255,255,255,.96)` + blur;
  странице добавить нижний отступ = высота панели + `env(safe-area-inset-bottom)`; чат-виджет
  поднять выше панели. Панель скрывается, если у места нет телефона.
- Лента миниатюр — горизонтальный скролл, `scroll-snap`.
- В мобильном блоке оценки звёзды и подпись идут В КОЛОНКУ, не в строку (в строке подпись
  зажимается в 62 px и рвётся на 4 строки).
- Любая интерактивная цель — минимум 44×44.

## Анимации

Все — на CSS, `transition` 180–280 мс, `cubic-bezier(.2,.8,.3,1)`; обязательно
`@media (prefers-reduced-motion: reduce) { animation: none !important; transition: none !important }`.
- Появление галереи и панели решения: `translateY(14px)` + fade, задержка второй 80 мс.
- Кроссфейд кадра галереи при переключении.
- Hover: карточки — тень и рамка `--brand-celadon`; стрелки — `scale(1.08)`; миниатюры — `translateY(-3px)`;
  основная CTA — `translateY(-2px)` с усилением тени; строки тарифов, дней и контактов — подсветка `#F7FAF7`.
- «Bu gün açıq» — пульсирующая точка 8 px (2 s).
- Избранное — короткий `scale(1.24)` pop при включении.
- Полосы гистограммы отзывов — анимация ширины 600 мс.
- Скелетоны: shimmer только на плейсхолдерах, пока грузятся реальные фото/карта; на загруженном
  контенте бесконечных анимаций быть не должно.
- `:focus-visible` — обводка 3 px `--brand-celadon` с offset 2 px на всех кнопках и ссылках.

## Крайние случаи (обязательно предусмотреть)

- Нет фото → плашка «Bu məkanın hələ fotosu yoxdur», стрелки/счётчик/миниатюры скрыты; одно фото →
  без счётчика и миниатюр.
- Цена: точная, «от», диапазон, «Pulsuz», «Qiymət dəqiqləşdirilir», смешанное «Pulsuz — 12 ₼».
- Расписание: по записи, «Bağlıdır», «24 saat», два интервала в день, полное отсутствие.
- Нет контактов → «Məlumat təklif et»; WhatsApp только если есть номер; нет координат → секция карты
  не рендерится вообще (не пустая рамка).
- Название до 255 символов не должно ломать сетку; описание отсутствует в текущем языке → секция скрыта.

## Что сохранить обязательно

Все существующие `data-track-*` атрибуты и события аналитики, JSON-LD разметку места, canonical/hreflang,
lazy-loading изображений, атрибуты доступности (`aria-label` на иконочных кнопках, `aria-current`),
серверную валидацию формы отзыва и защиту от повторного отзыва.
