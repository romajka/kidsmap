# Handoff: Личный кабинет KidsMap («Мой профиль»)

## Overview
Новая страница личного кабинета для kidsmap.az. Один тип пользователя: любой зарегистрированный
может сохранять места в избранное, писать отзывы и добавлять свои места. Отдельного интерфейса
«владельца бизнеса» нет.

Цель UX: за 2–3 секунды пользователь понимает — что у него есть → что сейчас происходит →
требуется ли от него действие. Никакого дублирования цифр, статусов и действий.

## About the Design Files
Файлы в этом бандле — **дизайн-референс в HTML** (прототип, показывающий вид и поведение),
а не продакшн-код для копирования. Задача: **воспроизвести дизайн в существующем окружении проекта**
(Django-шаблоны + ваш CSS/Tailwind/Alpine, либо React — что уже используется), опираясь на принятые
в кодовой базе паттерны. HTML-прототип открывается в браузере и служит эталоном разметки, цветов,
отступов, состояний и анимаций.

## Fidelity
**High-fidelity.** Цвета, типографика, отступы, радиусы, состояния и анимации финальные —
воспроизводить попиксельно средствами вашего фронтенда.

## Interactions & Behavior
- Переключение разделов: контент появляется `fadeUp .26s ease both` (`opacity 0→1`, `translateY(8px)→0`).
- Каскад списков: та же анимация с `animation-delay` 0 / .05 / .10 / .15s.
- Hover карточек: подъём 2–3 px, смена `border-color`, мягкая тень; все переходы 150–300 мс, `ease`.
- Кнопки: смена фона + `translateY(-2px)` на hover.
- Прогресс-бар: заливка растёт от 0 (`@keyframes grow { from { width: 0 } }`) 500 мс.
- Тост: `position: fixed; bottom: 24px; left: 50%; translateX(-50%)`, `#17332A`, белый текст, pill,
  тень `0 10px 26px rgba(23,51,42,.2)`, вход `toastIn .24s ease`, автоскрытие через 2600 мс.
  Появляется: после сохранения настроек и после удаления из избранного.
- Переключатель AZ/RU меняет **весь** интерфейс: подписи, статусы, даты и склонения.
- Русские числа обязательно склонять: 1 отзыв / 2–4 отзыва / 5+ отзывов (учитывать 11–14 → «отзывов»).
  Для азербайджанского — «rəy» без изменений.

## State Management
Состояние страницы (или Alpine/React-стейт):
- `lang`: 'az' | 'ru' (по умолчанию из настроек пользователя; переключатель в шапке).
- `tab`: 'overview' | 'places' | 'reviews' | 'favs' | 'settings' (синхронизировать с URL).
- `filter`: 'all' | 'draft' | 'moderation' | 'published' | 'fix' — только для «Моих мест».
- `toast`: строка + таймер 2600 мс.
- `notify`: { moderation, reviews, digest } — булевы.
- Удаление из избранного — оптимистично (сразу убрать из списка + тост), затем запрос.

Данные с бэкенда:
- места пользователя: id, название, категория, район, статус (draft/moderation/published/fix),
  процент заполнения, рейтинг, количество отзывов, короткая человеческая подсказка (если требуется действие), фото;
- отзывы пользователя: место, оценка 1–5, текст, дата, статус модерации, причина отклонения;
- избранное: место, категория, район, рейтинг, количество отзывов, фото;
- профиль: имя, email, аватар, дата регистрации, язык, настройки уведомлений.

Пустые состояния обязательны для: мест нет, избранного нет, отзывов нет, по фильтру ничего не найдено.
