# KidsMap AI Handoff

Этот файл — подробный контекст для нового AI-чата или нового ассистента.

Если работа продолжается в новой сессии, **начинать нужно с чтения этого файла**, а уже потом смотреть код и предлагать изменения.

## 1. Что это за проект

`KidsMap` — каталог детских кружков, секций и курсов в Баку.

Основная идея:

- родитель быстро находит кружок по району, метро, возрасту, цене и отзывам
- владелец кружка может получить управление карточкой через ownership-заявку
- модератор контролирует качество карточек, ownership-заявок и части пользовательского контента

Проект уже в активной разработке, поэтому важно **не переписывать всё с нуля**, а аккуратно продолжать существующую систему.

Нельзя ломать:

- отрезать обычного пользователя от ownership-заявок
- поломать owner-кабинет
- сломать soft-delete карточек
- сломать moderation flow

## 12. Известные технические риски

### MariaDB warnings

На проде есть известные warnings от Django, что MariaDB не поддерживает часть `UniqueConstraint(..., condition=...)`.

Это не означает, что деплой сломан, но означает:

- часть уникальности гарантируется приложением, а не БД
- при изменениях в likes/reactions/reviews это нужно помнить

### Cloudflare / browser cache

После правок CSS/JS можно получить ложный вывод “ничего не поменялось”, если:

- браузер держит старый CSS
- Cloudflare отдаёт старую статику

### Прод-дерево может содержать stash/local edits

Перед `git pull` на сервере проект уже иногда упирался в локальные server changes. Поэтому там часто используется:

```bash
git stash push -m "before-deploy"
```

Правильный порядок:

1. Не спорить и не гадать.

5. Проверить `collectstatic`.
6. Проверить локализацию, если проблема связана с языками.

## 14. Что делать, если пользователь просит “запушь всё”

Нужно сначала:

1. `git status`
2. убедиться, что нет мусора
3. `check`
4. `makemigrations --check --dry-run`
5. `test`
6. только потом commit/push

Нельзя blindly пушить непроверенный worktree, особенно если там:

- незавершённые UI-правки
- большие locale diff
- новые static-файлы
