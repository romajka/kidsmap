- `services/catalog_conversion.py:apply_plan`: малые атомарные batches, run/source `SELECT FOR UPDATE`, fingerprint recheck перед ledger write, checkpoint в той же транзакции. Устаревший/missing source переводится в `changed_source` с пустым target; более свежий mapping не перетирается старым планом. Повтор и продолжение ограничены unique key и checkpoint. - `services/catalog_conversion.py:reconciliation` сравнивает агрегаты Place/PricingPlan/PlacePhoto/PlaceLike/PlaceReview/PlaceReviewReaction с baseline, выдаёт состояния/reason counts и checkpoint без приватных записей.
- `management/commands/convert_task33_catalog.py`: `--dry-run --plan /tmp/...` создаёт один приватный mode0600 plan file вне Git и не перезаписывает старый. `--apply` требует сохранённый план, проверенный disposable QA04 PostgreSQL/socket и batch limit; эта версия команды преднамеренно закрыта для production.
