## Как запускать

1. Открой тот же рабочий проект в новом диалоге.
2. Проверь [implementation-status.md](implementation-status.md): выбранный этап разрешён зависимостями, другого active_run нет.
3. Открой файл этапа из таблицы и вставь весь текст в диалог. При доступе к файловой системе можно вместо копирования использовать короткие команды из [start-prompts.md](start-prompts.md).
4. Дождись результата, exact checks и обновления журнала. Следующий этап отправляй в новый диалог. Исправление незавершённого этапа продолжай в его текущем scope.

Одно задание — один проверяемый результат; оно может потребовать нескольких сообщений. 28 промптов не обещают ровно 28 ответов. Если этап стал слишком большим, исполнитель фиксирует numbered подэтапы и зависимости в журнале, сохраняя общий контракт; не начинает весь следующий domain без поручения.
