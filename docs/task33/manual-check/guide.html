Как пользоваться

  1. Оставьте эту инструкцию в отдельной вкладке. Ссылки на страницы открываются в новой вкладке.
  2. Перед каждым сценарием выберите нужную роль ниже. Переключение действует на все обычные вкладки этого браузера. Для одновременной проверки гостем используйте окно инкогнито.
  3. Выполняйте пункты по порядку. Сначала проверьте исходные данные, затем редактирование, в самом конце — отделение филиала.
  4. Ставьте отметку только после проверки ожидаемого результата. Отметки сохраняются в этом браузере; они не означают автоматическое прохождение теста.

Данные созданных карточек — вымышленные. Контакты в общей шапке и подвале сайта могут быть штатными. Письма наружу не отправляются. Не звоните по тестовым номерам. Для проверки загрузок используйте вымышленные документы.

Запуск, данные и границы проверки

Основной адрес: http://localhost:8780/ru/. Сервер слушает только локальный адрес. База PostgreSQL изолирована от сети; приложение использует отдельные медиа, сессии, кеш и почту в памяти. Все обычные маршруты Django доступны, бизнес-формы и проверки прав настоящие.

Для повторного запуска откройте PowerShell:

wsl -d Ubuntu-24.04 -- /root/kidsmap-task33/.venv/bin/python /mnt/c/kidsmap/docs/task33/manual-check/qa/start.py

Остановить только сайт, сохранив базу:

wsl -d Ubuntu-24.04 -- /root/kidsmap-task33/.venv/bin/python /mnt/c/kidsmap/docs/task33/manual-check/qa/start.py stop

Повторный запуск не сбрасывает ваши правки. PostgreSQL хранится в отдельном Docker volume kidsmap-manual-20261004-data. Медиа и служебные файлы находятся в WSL /tmp/kidsmap-task33-qa04-manual20261004; очистка временных файлов может их удалить. Не используйте стенд для ценных данных. Если изменены исходники, запуск остановится на проверке снимка — стенд нужно обновить осознанно.

Google-вход, реальная почта, геокодирование и аналитика с внешними ключами отключены. Интерактивная Google-карта и поиск адреса не работают без ключа: доступна панель со счётчиком точек и сообщением о недоступности карты. Это ограничение данного стенда, а не доказательство прохождения карты. Публичные шрифты требуют интернет в браузере. Ошибка внешнего ресурса не проверяет серверные маркеры, но её нужно записать отдельно. Полноценная проверка доставки письма, аварийных повторов, конкурентной передачи владения и восстановления — в автоматическом отчёте; нажатиями в браузере эти гарантии не доказываются.

Если нашли проблему, запишите: номер шага → роль → URL → язык и ширина окна → действия → что ожидали → что увидели. Приложите скриншот и текст ошибки из консоли (F12 → Console). Не скрывайте неожиданные ошибки.
