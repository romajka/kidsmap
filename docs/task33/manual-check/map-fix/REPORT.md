# Исправление плиток «Access blocked» на главной — 04.10.2026

На локальной главной странице карта снова загружается. В проверке реального OpenStreetMap все 15 плиток видимой области вернулись с HTTP 200. При HTTP 403 или недоступной сети изображения ошибки не показываются: появляется локализованное сообщение со ссылкой на каталог, метки и карточки мест остаются доступны.

[Открыть главную](http://localhost:8780/ru/#home-map-section) · [Карта после исправления](screenshots/map-fixed-live.png) · [Проверка](verification.json)

## Причина и изменение

Глобальный `Referrer-Policy: same-origin` запрещал передавать Referer запросам внешнего сервиса. До исправления браузер отправлял запросы OSM без этого заголовка. Кроме того, обычный `<img>` успешно отображал PNG из ответа HTTP 403; одного обработчика ошибки изображения было бы недостаточно. Воспроизведение: `browser-red.json`, 15 таких изображений на экране, отсутствие сообщения об ошибке.

В `static/js/home_map.js` загрузка плитки теперь проверяет HTTP-статус до отображения изображения. Запросы используют канонический URL `tile.openstreetmap.org`, передают настоящий origin через `strict-origin-when-cross-origin`, без cookies, пути страницы и строки запроса. Браузерный кеш не отключается. Глобальная политика сайта остаётся `same-origin`.

При отказе слой фона снимается и ожидающие запросы отменяются; замены провайдера или циклических повторов нет. Object URL освобождаются после загрузки/ошибки и при удалении плитки. У запроса ограничение ожидания 15 секунд. В шаблоне главной добавлены сообщения AZ/RU/EN и новая версия JS-ресурса.

Решение соответствует требованиям [OSM Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/): корректный URL, Referer, обычное кеширование и видимая атрибуция. Загрузка реализована через публичный интерфейс [Leaflet TileLayer](https://leafletjs.com/reference.html#tilelayer). Внешний сервис не гарантирует постоянную доступность, поэтому обработка отказа проверена отдельно.

Команда JS: `node --test scripts/tests/home_map_tiles.test.cjs scripts/tests/home_map_filters.test.cjs`. Браузерные команды и сценарии сохранены рядом: `browser-rejected.js`, `browser-live.js`, `browser-matrix.js`; результаты — соответствующие JSON/log.

Первый диагностический `browser-live-intercepted.log` ещё содержал перехват тестового HTTP 403 и **не считается проверкой реального сервиса**. Перехваты явно сняты через `unrouteAll`; доказательство реального ответа — последующий `browser-live.json`. В `browser-matrix-abort-review.log` первоначально отменённые запросы после снятия слоя были отмечены как неожиданные. Финальный сценарий допускает только конкретные ожидаемые сетевые ошибки тестового OSM-запроса; прочие ошибки продолжают проваливать проверку.

## Область и сохранность

Изменены два файла приложения и добавлен один JS-тест. Исходные версии сохранены в `before/`. Новый runtime: `/root/km-manual-mapfix`; манифест — `../source-manifest.json`. Локальный сервер оставлен на 8780, синтетическая база и пользовательские тестовые правки сохранены. Старый runtime `/root/km-completion-browser` и материалы `completion/` / `final-audit/` не редактировались.

Полный backend-набор в этом исправлении не повторялся: изменение касается JS и шаблона главной. Google-карта каталога по-прежнему требует отдельного ключа. Production, commit/push/deploy не выполнялись.
