## Повторение

Инспекция без изменения данных:

```powershell
wsl -d Ubuntu-24.04 -- /root/kidsmap-task33/.venv/bin/python /mnt/c/kidsmap/docs/task33/manual-check/qa/add_demo_places.py
```

Добавление недостающих записей:

```powershell
wsl -d Ubuntu-24.04 -- /root/kidsmap-task33/.venv/bin/python /mnt/c/kidsmap/docs/task33/manual-check/qa/add_demo_places.py --apply
```

Браузерный проход (предварительно открыть сессию demo100):

```powershell
wsl -d Ubuntu-24.04 --cd /root/task33-browser-tools -- env PATH=/root/task33-browser-tools/node_modules/.bin:/usr/local/bin:/usr/bin:/bin playwright-cli -s=demo100 run-code --filename /mnt/c/kidsmap/docs/task33/manual-check/demo100/browser.js
```
