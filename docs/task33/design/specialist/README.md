## Просмотр

Открывайте через локальный static HTTP server с корнем репозитория: [галерея](index.html?lang=ru). Пакет использует только существующие локальные assets: `../owner/prototype.css`, `../../../../static/img/logo-mark.svg`, Chiron PublicSubset и MaterialSymbolsRounded из static/fonts. Принятые owner/shared03 файлы не изменены. CDN, API, DB, почта, внешние ссылки, auth и реальная загрузка отсутствуют. File input читает только локальное имя/размер для демонстрационной проверки; байты никуда не отправляются и не сохраняются. В браузерном storage ничего не записывается.

Языки `?lang=az`, `?lang=ru`, `?lang=en`; страницы и подписи состояний переведены. Размеры проверки:320/360/390/768/1024/1280/1440. Поддерживаются semantic buttons/labels, native keyboard controls, видимый focus, skip link, связанная ошибка с `aria-invalid`/`aria-describedby`, live result и reduced-motion, унаследованный из owner CSS. Состояния переключаются в нижней демонстрационной панели; это не переключение реальных прав пользователя.

`default`, `empty`, `pending`, `active`, `history`, `error`, `conflict`, `denied`, `rejected`, `approved`, `withdrawn`, `saved`, `revoked`, `loading` — сценарии демонстрационной панели, а не новый frontend domain enum. Их применимость зависит от экрана согласно таблице. Реализация получит server-derived permissions, states, versions и immutable IDs. Общие error/conflict/loading notices не имитируют успешную запись. Native file chooser содержит локализуемые браузером/ОС системные подписи; проект переводит его label, help и errors, а не browser chrome.

Синтетический `consent=person|organization` у pending показывает, какая сторона уже подтвердила. После отмены `consentHistory=both|person|organization|none` сохраняет ранее показанные события; [отмена после двух согласий](organization.html?lang=ru&state=history&consentHistory=both) отличается от [отмены после одного](organization.html?lang=ru&state=history&consentHistory=person). Это query fixtures, не backend schema или inference. Переключение языка сохраняет выбранный actor/consent/history. В исходном default обе стороны ожидаются; только второе отдельное подтверждение делает связь active.

## Контракты и source references

- decisions.md **D08**: один профиль человека; автор/Org не получают владение, claim проверяет KidsMap; личные сведения/документы не доступны через Place/Org grants.
- `src/catalog/models/specialist.py:Specialist`, `SpecialistDocument`: separate verified_person_user/person_verified_at; private storage/purpose, opt-in actor/time. Public certificate требует eligible published active specialist, текущий active verified account, approval и explicit opt-in. Публичный экран показывает только синтетическую квалификацию, удовлетворяющую этим условиям; identity evidence отсутствует в public DOM.
- `src/catalog/services/specialist_documents.py:is_public_document`, `set_document_public_choice`, `review_document`: проверка и выбор публикации разделены; private viewing в макете не ACL proof. Копия реальных документов не используется.
- `src/catalog/models/specialist_domain.py:SpecialistClaim`, `SpecialistEmployment`, `SpecialistEmploymentEvent`; services/specialist_domain.py `review_claim`, `confirm_employment`, `cancel_employment`: отдельные подтверждения, роль/период, cancellation/history. Demo actor selector — явно обозначенный переключатель синтетического сценария, без session или настоящих прав.
- `src/catalog/services/owner_specialist_use_cases.py`: online не удаляет историю мест. Independent/private office означает собственную практику, не выдуманную политику секретности адреса. Публичный демонстрационный адрес допустим.
- `src/catalog/domain_admin/specialist.py`: dedicated document review доступен отдельно от generic staff; claim и document permissions различаются. Демонстрационный reviewer имеет оба; обычный staff получает denied. Это не provision permissions и не backend test.

Фиксированная дата данных макета: **2026-10-03**. Текущая подтверждённая связь имеет начало01.09.2026 без end_date. Прошлая связь закончилась30.06.2025, даже если исторически обе стороны подтверждали участие; она отдельно от current work. Cancellation показывает прежнюю роль/период и отдельную дату отмены03.10.2026 в history, не меняет start/end и не стирает события. При реальной интеграции классификация upcoming/current/past должна учитывать server даты, не только ACTIVE status.

## Ограничения и принятие

Ни один UI control не доказывает backend ACL, CAS, race safety или фактическую сохранность данных. Nested ID/person-vs-org/old URL checks, PostgreSQL fixture transfer, реальная private media migration, file scanner и real integrations **NOT RUN** в design-only. Файлы private documents не доступны по public URL: макет не содержит таких ссылок и не обращается к реальным файлам. Stage24 backend evidence сохраняется отдельно.

После независимого browser review root обновляет reports/25.md и design/acceptance.md, показывает конкретный specialist-25-r1 пользователю и фиксирует REVIEW_PENDING. Полный этап25 не DONE до принятия новых экранов, application integration и требуемых isolated checks. Этап26/production/commit/push не выполняются.
