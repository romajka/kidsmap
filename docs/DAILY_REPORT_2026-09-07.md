## Что относится к сегодняшнему дню

До начала этой задачи коммитов за 7 сентября не было. Рабочее дерево содержало накопленные изменения, в том числе работы за 6 сентября; Git не позволяет достоверно датировать каждую незакоммиченную строку. Поэтому весь отправляемый пакет нельзя считать разработанным за один день.

В отчёте `GOOGLE_OAUTH_PRODUCTION_STATUS_2026-09-07.md` зафиксирована сегодняшняя подготовка Google OAuth: настройка Client ID, защита контекста Docker от попадания `.env` и временных файлов, проверка callback/HTTPS и изолированные проверки авторизации. Эти сведения взяты из предыдущего отчёта; в текущей задаче сервер повторно не проверялся.

Сегодня в рамках сохранения изменений выполнены свежие локальные проверки и подготовлен этот отчёт. Все обычные tracked/untracked файлы включаются в коммит; игнорируемые `.env`, базы, media, временные файлы и локальные тестовые журналы в пакет не добавляются.

## Граница публикации

В `.github/workflows/deploy.yml` push в main запускает quality, затем production deploy. Для выполнения запроса на сохранение в Git при действующем запрете на изменения production новый коммит получает `[skip ci]`: это пропускает данный push workflow, включая CI и автоматическую выкладку. Механизм описан в [документации GitHub](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/skip-workflow-runs).

Workflow не изменён. Следующий push без skip-маркера снова может запустить деплой. До него необходимо отдельно решить блокеры миграции/OAuth и согласовать production release. В текущей задаче production-команды не выполнялись. Факт и хеш успешной отправки подтверждаются в итоговом сообщении после проверки удалённой ветки.
