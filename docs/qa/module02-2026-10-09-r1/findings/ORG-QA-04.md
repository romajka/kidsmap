# ORG-QA-04 — административный редактор организации частично остаётся русским

OPEN, P3; высокая уверенность. Роль: администратор; `/admin/catalog/organization/add/` и `/admin/catalog/organization/4/change/`. Локальный Chromium и текущие `.po`, пересобранные исключительно для нового QA стенда.

Переключить язык AZ/EN в той же браузерной сессии, открыть редактор. Поле названия переводится корректно, но вкладка «Названия» и часть статических заголовков («Организации», «Владение», «Проверка данных», «Связанные разделы», «Текущие и предложенные данные») остаются на русском. Ожидание: административные подписи соответствуют выбранному языку. Это отдельный остаточный дефект перевода, а не старый finding о frozen labels отдельных полей.

Проверенные причины этих двух строк — отсутствие доступного перевода/fallback. Для остальных подписей механизм требует отдельного исследования; не утверждается одна общая причина. Реальная data/moderation state этим не меняется.
