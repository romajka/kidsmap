## Границы

Настоящая устаревшая заявка остаётся устаревшей: для её принятия нужна новая актуальная отправка. Заявка на владение и публикация места — разные решения.

Миграции и массовое исправление данных не запускаются. Полный цикл approve/reject/publish/hide с реальными записями на production не повторяется; он подтверждён локально. На production проверяются source/image/MO/config/health и GET в существующей авторизованной сессии. Generic Python HTTPS-запросы к admin edge получают 403, поэтому административные страницы проверяются native browser и direct-origin HTTP; это отражено в [r1 edge.json](../admin-moderation-release-2026-10-16-r1/edge.json).

Внешние OAuth/почта/Maps/GA, физические телефоны, Firefox/WebKit, screenreader и нагрузочный тест не входят в эту проверку. Backup integrity и читаемость metadata проверяются; отдельный restore drill не выполняется. Локальный HEAD/index и остальные dirty/untracked изменения сохранены. Push/merge в main не выполнялись.

## Точный состав проверки и два прежних локальных изменения

Финальная сверка нашла два отличия LOCAL WORKTREE от замороженного production-пакета: `src/catalog/controllers/typed_reviews.py` и `src/catalog/templates/catalog/typed_reviews.html`. Они уже присутствовали в исходном audit snapshot до работы над восьмью дефектами: это показ последней причины отклонения автору и восстановление выбранной оценки в публичной форме. Они не входили в отдельный патч этой задачи и не добавлялись в production. Точное подтверждение — [source-boundary.json](source-boundary.json). Эти файлы в рабочем дереве сохранены.

Поэтому исходные 165 локальных тестов нельзя целиком объявлять прогоном точного серверного состава. В попытке повторить первоначальный список 79 на замороженном release snapshot фактически выполнились 72 core review tests; дополнительный `test_social_qa01_rating_readback` отсутствует в базовом релизе и дал один ModuleNotFoundError (73 tests, errors=1). Это ошибка выбора QA-модуля для другого состава, а не зелёный прогон и не новая ошибка production. Исходный лог сохранён в restricted scratch; assertions не менялись.
