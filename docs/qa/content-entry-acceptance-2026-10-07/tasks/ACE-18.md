# ACE-18: Перевод действия «Удалить» отображается как «Удалил»

Приоритет: **P3**. Роль: **модератор**. Среда: LOCAL, изолированный PostgreSQL/QA, текущий WORKTREE. Дата: 2026-10-07. Уверенность: высокая.

URL: [локальный сценарий](http://localhost:8783/admin/catalog/specialist/4/change/). Код стенда: HEAD 2da9d33abbc53d1ac71bcb7e15a0170bef6277d5 + зафиксированный WORKTREE (source digest 146a8499b61ea65cfe70640f38816d1ee83b903f877d46a9bf06fa5a47e27a9a).

## Воспроизведение

1. Открыть RU редактор специалиста.
2. Прочитать название удаления (после проверки контраста через DOM).

## Ожидание

Кнопка подписана действием «Удалить».

## Фактический результат

DOM содержит «🗑 Удалил».

## Первопричина и область исправления

locale/ru msgid «Удалить» имеет msgstr «Удалил». Строка общая для других административных страниц.

Источник: [locale/ru/LC_MESSAGES/django.po:1142](/home/ramin/kidsmap/locale/ru/LC_MESSAGES/django.po:1142).

Предлагаемый scope: Исправить общий перевод и перепроверить потребителей удаления, не менять поведение удаления.

Предлагаемый владелец исправления: **локализация/frontend-admin**. Зависимости: Все потребители общей строки Delete; существующее действие удаления не менять. Следующий шаг: согласовать этот отдельный scope, исправить и повторить указанный сценарий на изолированной QA.
