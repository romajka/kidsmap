# ACE-05: Частичный черновик мероприятия без категории возвращает HTTP 500

Приоритет: **P1**. Роль: **владелец**. Среда: LOCAL, изолированный PostgreSQL/QA, текущий WORKTREE. Дата: 2026-10-07. Уверенность: высокая.

URL: [локальный сценарий](http://localhost:8783/ru/account/places/events/create/). Код стенда: HEAD 2da9d33abbc53d1ac71bcb7e15a0170bef6277d5 + зафиксированный WORKTREE (source digest 146a8499b61ea65cfe70640f38816d1ee83b903f877d46a9bf06fa5a47e27a9a).

## Воспроизведение

1. Выбрать доступную организацию.
2. Ввести название; категорию оставить пустой.
3. На первом этапе нажать «Сохранить черновик».

## Ожидание

Работает частичный черновик либо возвращается понятная ошибка формы.

## Фактический результат

IntegrityError: null value in column category violates not-null constraint. Карточка не создана.

## Первопричина и область исправления

В draft_save_only все поля становятся необязательными; _values передаёт category_id=None в create_event при NOT NULL в PostgreSQL.

Источник: [src/catalog/forms.py:2017](/home/ramin/kidsmap/src/catalog/forms.py:2017).

Предлагаемый scope: Согласовать неполный черновик с существующей моделью хранения и контролируемой валидацией. Не менять требования публикации.

Предлагаемый владелец исправления: **backend мероприятия**. Зависимости: Draft transport и существующая категория; не ослаблять требования публикации. Следующий шаг: согласовать этот отдельный scope, исправить и повторить указанный сценарий на изолированной QA.
