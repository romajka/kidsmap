# Выполнение и повторная проверка

Работу выполнял основной агент последовательно в действующем разрешении пользователя на весь модуль 12 и возникающие связанные исправления. Независимая проверка другим агентом не заявляется.

Точные команды, имена свежих тестовых БД, exit codes и идентификаторы методов записаны в `stages/*/evidence/*.json` и `evidence/final-backend.json`. В итоговом прогоне — 586 уникальных методов. Его снимок исходников находится в `evidence/final-backend-source.json`, список меток — в `evidence/final-current-labels.json`.

```text
docker exec m12full-r1-app python /mnt/c/kidsmap/.tmp/m12-full-r1/runtime_full2.py test <метки из final-current-labels.json>
```

Профиль очищает окружение, включает DJANGO_TESTING=1 и проверяет хеши исходников/изолированных MO до django.setup. Свежая итоговая БД — `test_m12full_r2`; PostgreSQL доступен только через loopback собственного app namespace. DB/cache/media/private-media/email отдельные, интеграции отключены. Первый широкий успешный прогон на 583 метода сохранён как `before-read-beacon-*`; он предшествует двум дополнительным исправлениям и не заменяет итоговый прогон.

Новые проверки отправителя выполнялись командой:

```text
npx --yes --package node@24 node scripts/test_analytics_sender.cjs C:/kidsmap
```

AI referral и phone DOM команды записаны в `evidence/javascript.json`. Node 18 не смог загрузить установленный jsdom из-за ESM; исходный неудачный результат сохранён, успешный запуск использовал уже применявшийся Node 24 без изменения тестов/зависимостей. Phone DOM — симуляция браузерных API, не замена нативным проверкам.

Принятые 16 браузерных наборов перечислены в `verification.json`. Проверены AZ/RU/EN и ширина 360/390/768/1024/1280/1440 px, права, клавиатура, данные, ошибки, повторная загрузка, реальные локальные счётчики и сохранение через UI. GA snapshots, отказ записи/чтения, выключенное хранилище и отказ Beacon явно помечены SIMULATED. Реального Google/внешних контактов нет.

Ошибки собственных наблюдателей/фикстур, неудачные монолитные сценарии после неподдержанного tel, исправления native-apply и QA-профиля сохранены. Они не включены в успешные счётчики. Исходные assertions не менялись. Сквозные outbound-действия проверялись независимо в новых контекстах; ограничение headless dialer остаётся указанным.

Скрипты в `execution-scripts/` — архив выполнения, а не готовая команда повторного запуска. Имена БД уже использованы, source guards ожидают конкретные хеши; для новой проверки нужны новые имена ресурсов и новый QA-пакет. Архив QA-профиля содержит только фиксированные вымышленные параметры стенда, без production credentials. Его финальные retention/collection-start значения добавлены при проверке QA-конфигурации; это не изменение приложения или production env.

Пакет проверяется без записи файлов:

```powershell
wsl -d Ubuntu-24.04 -- env PYTHONDONTWRITEBYTECODE=1 python3 /mnt/c/kidsmap/docs/qa/module12-repair-2026-10-18-pc-r1/verify_artifacts.py
```

Проверка сверяет манифест, текущий снимок приложения, старые тесты, 43 предыдущих пакета, документы, refs/index и сводные результаты. После дальнейших изменений приложения проверка рабочего дерева закономерно перестанет проходить; исторический PASS относится к сохранённому снимку.

Четыре старых m09 standby-контейнера завершились по истечении настроенного sleep(86400), exit 0/OOM false. Их IDs и данные сохранены; задача их не перезапускала и не останавливала. См. `evidence/foreign-runtime-transitions.json`. Это явно отделено от неизменности исходников и QA-пакетов.

Сырые HTML ответов с CSRF/cookies, реальные секреты и production records в пакет не включались. Реальные внешние интеграции, CI execution, production, commit/push/deploy не выполнялись.
