# Выполнение и повторная проверка

Работу выполнял основной агент последовательно. Независимая проверка другим агентом не заявляется.

Итоговый backend-прогон содержит 514 уникальных тестовых методов, выполненных на свежей изолированной БД `test_m11dbguard_r2`. Точная команда и результаты находятся в `evidence/final-backend.json`, список модулей — в `evidence/final-current-labels.json`, снимок исходников — в `evidence/final-backend-source.json`.

Команда запуска внутри собственного QA-контейнера:

```text
docker exec m11full-r1-app python /mnt/c/kidsmap/.tmp/m11-full-r1/runtime-guard-final.py <метки из final-current-labels.json>
```

Профиль очищает окружение, включает `DJANGO_TESTING=1`, проверяет хеши исходников и использует отдельные DB/cache/media/private-media/email и отдельно скомпилированные переводы. PostgreSQL доступен только через loopback собственного контейнера. Реальные внешние интеграции выключены.

Ранние широкие прогоны на 487 и 512 методов завершились с ошибками окружения; они сохранены и не считаются успешными. Последовательно исправлены конфигурация origin, реальная конфигурация изолированного PostgreSQL и доступность объявленной зависимости `pypdf==6.20.1` для дочернего sanitizer-процесса. Официальный wheel проверен по SHA-256 и установлен в собственный QA-контейнер. Исходные тесты не изменялись.

Пять принятых браузерных наборов перечислены в `verification.json`. Действия выполнялись через обычные элементы интерфейса Chromium. Проверены три языка и шесть размеров экрана; отказ загрузки фото явно обозначен как симуляция. Код наблюдателей и исправления ошибок самих наблюдателей сохранены. Это 2635 отдельных утверждений, а не 2635 разных пользовательских сценариев.

Скрипты выполнения сохранены в `execution-scripts/` для аудита. Их нельзя слепо запускать повторно: имена свежих БД уже использованы, а сохранённые проверки ожидают конкретные снимки исходников. Для нового прогона нужен новый изолированный профиль и новые имена ресурсов. Не использовать production credentials.

Пакет можно проверить без запуска тестов и без записи файлов:

```powershell
wsl -d Ubuntu-24.04 -- env PYTHONDONTWRITEBYTECODE=1 python3 /mnt/c/kidsmap/docs/qa/module11-repair-2026-10-18-pc-r1/verify_artifacts.py
```

Проверка сверяет манифест, текущие исходники, неизменность старых тестов, 42 предыдущих пакета, документы, Git refs/index и сводные результаты. После будущих изменений проекта проверка текущего рабочего дерева закономерно перестанет проходить; исторические результаты относятся к сохранённому снимку.

Сырые логи с HTML ответов, CSRF/cookies и секретами в пакет не включались. Production, реальные поисковые боты и внешняя индексация не проверялись; commit/push/deploy не выполнялись.
