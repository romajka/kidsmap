## Исправление и причина

Шаблон `src/catalog/templates/admin/catalog/place/form/section_location.html:59` содержал ручное утверждение об обязательности адреса и точки. RU/AZ/EN переводы повторяли это утверждение. При этом `place_readiness.py:462` исключает coordinates из blocking requirements. Свежий probe Place154: опубликована, адрес заполнен, lat/lng NULL, поля lat/lng required=False, готовность10/10. Rendered RED:3/3 языка показывали неверное требование. Исторический отчёт не использован как доказательство текущего поведения.

Новый текст: **«Точка на карте необязательна. Рекомендуем указать её; можно вернуться к карте позже.»** AZ: «Xəritədə nöqtə qeyd etmək məcburi deyil. Qeyd etməyi tövsiyə edirik; xəritəyə sonra qayıda bilərsiniz.» EN: «A map pin is optional. We recommend adding it; you can return to the map later.»

Изменены только одна строка шаблона и соответствующий ключ трёх PO/MO,7 файлов. Literal search по src/static/locale обнаружил единственное использование старого ключа в приложении. Все другие исходные файлы побайтно сохранены, все другие записи переводов, включая context/plural, сравнивались отдельно и сохранились. MO обновлены по существующим каталогам, без перегенерации остальных переводов из PO. Python/JS/CSS, обязательность адреса, координат, publication, ACL и canonical transitions не менялись. Schema/migrations отсутствуют.
