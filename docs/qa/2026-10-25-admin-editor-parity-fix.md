## Воспроизведено и исправлено

- Верификация использовала сетку 200/742 px: добавленный настоящий предпросмотр стал третьим элементом, список требований попал в колонку 200 px. Теперь проверка занимает доступную ширину, действия и выбор языка сгруппированы, имитация карточки удалена; сохранён настоящий предпросмотр страницы.
- Под общим выбором фото оставались отдельные пустые загрузчики обложки/галереи. После успешного подключения общего picker они скрываются. Fallback-поля остаются в форме, их native formset/валидация и приватные черновики сохранены.
- Главное фото заменяется отдельной кнопкой; карточки галереи имеют «Сделать главным», «Заменить», стрелки порядка и удаление. На узком телефоне одна колонка; повторные флажки удаления скрыты.
- В админке выбор главного фото теперь **меняет его местами с обложкой**, как в форме сайта. Без прежней обложки выбранный элемент удаляется из галереи. Для сохранённых снимков оба файла загружаются до изменения полей; ошибка сохраняет исходное состояние, успешный повтор убирает ошибку.
- Набор удаляемых фото канонизирован: его порядок больше не зависит от DOM после сортировки/перезагрузки. Регрессия обнаружена настоящим смешанным циклом; иначе неизменённый черновик мог снова выглядеть изменённым.
- Мобильный указатель раздела теперь следует видимой секции, если ранее выбранное поле осталось за экраном. Внизу страницы обновляется и мобильный select.
- Открытие уже удалённой карточки больше не перенаправляется на тот же адрес: перехваченный на GET `ValidationError` теперь возвращает 404. Это обнаружено на собственной удалённой QA-записи при очистке; обычная действующая карточка продолжает открываться.
- Версии затронутых JS/CSS обновлены, чтобы браузер не использовал прежний asset. Браузерная регрессия и сценарий фото добавлены в CI.
