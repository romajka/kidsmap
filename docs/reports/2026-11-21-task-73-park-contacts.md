# №73. Парки без телефона и контакт администрации

**21 ноября 2026 года. Статус в ClickUp — «проверка».** Локальная реализация проверена. Выкладка на сайт отложена до общего релиза. Рабочая копия KidsMap на базе `5bb9af5f`. [Задача №73 в ClickUp](https://app.clickup.com/t/z8rctexru6)

## Что обнаружено и исправлено

| Сценарий | Результат |
| --- | --- |
| Добавление парка без телефона | Ранее основная форма уже допускала сохранение. Отдельная проверка качества основной админки ошибочно выдавала `MISSING_CONTACT`. Теперь она использует то же правило для парков, площадок и подтверждённых общественных пространств. |
| Волонтёр и модератор | Волонтёр может подать парк без прямого номера и предложить название и телефон администрации. Оба поля проходят обычную модерацию. |
| Контакт администрации | Добавлены два пустых по умолчанию поля. Для официального телефона нужно название организации. Одна организация без телефона также допустима. Связь с владельцем или коммерческой сетью для этого не требуется. |
| Редактирование опубликованного парка | В основной админке создание и редактирование используют разные перечни полей. Оба проверены на отрисованной странице и при сохранении. |
| Публичная карточка | Официальный номер раскрывается по нажатию в отдельном подписанном блоке. Прямые звонки и WhatsApp у парков без собственного телефона скрыты. Другие номера парка при их наличии остаются доступны. |
| Старый телефон KidsMap | Исторический номер футера распознаётся после нормализации. Для общественного пространства он исключается из публичного звонка, WhatsApp и телефона администрации. Исходные записи сохраняются для проверки. |

## Данные опубликованного сайта

21 ноября открытая карта вернула все 21 карточку категории «Парки и площадки» за один запрос. Кнопка звонка доступна у 7, WhatsApp у 5, у 14 обе кнопки отсутствуют. С разрешения пользователя выполнено ровно семь штатных раскрытий. Все семь вернули HTTP 200. Проверены все десять записей с телефонами для звонка и пять ссылок WhatsApp. [Публичная карта](https://kidsmap.az/ru/api/catalog/map/?category=parks-playgrounds)

В проектной таблице от 20 ноября подкатегория «Парки и бульвары» содержит 19 мест с учётом разных статусов публикации. Этот счётчик не подтверждает контакты отдельных мест. [Постоянные места](https://docs.google.com/spreadsheets/d/1t-GReQfONwt8ziO6mIw1lq1Dryh2F4TvavZw522y2FY/edit#gid=2031261120)

В локальном снимке от 6 сентября проверены 25 неудалённых мест. Правилу для парков соответствует одна опубликованная карточка с одним синтаксически корректным номером. Совпадений со старым номером KidsMap и с другими телефонами мест в этом снимке нет. Парк Низами в снимке отсутствует. Миграция `0033_update_footer_phone_default` подтверждает использование спорного номера футером KidsMap, но не записывает его в места. В официальном сообщении о реконструкции парка отсутствует телефон его администрации. [Официальное сообщение](https://president.az/en/articles/view/55150)

Проверка доказывает, что действующий сайт выдаёт старый телефон через кнопку каждой из трёх карточек. Установить, кто и когда внёс номер, по публичной выдаче нельзя. Прямого доступа к истории изменений базы в этой сессии не было. Номера в опубликованных карточках не редактировались. Для трёх парков со старым номером допустимо оставить прямой телефон пустым.
