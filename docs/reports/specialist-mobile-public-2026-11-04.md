- Гость сначала входит, затем пишет отзыв; `next` сохраняет `#reviews`. Оценка — настоящие radio с клавиатурой. При ошибке сети текст остаётся, повторная отправка доступна.
- Найден и исправлен дополнительный реальный сценарий: после истечения сессии вход в новой вкладке обновляет CSRF cookie, поэтому прежняя форма получала403. Транспорт теперь берёт текущий токен перед POST, сохраняя текст. Проверка в браузере:401 → вход в новой вкладке →200. CSRF-защита не отключалась; fetch ограничен same-origin. Основание: [Django6: CSRF и повторный вход](https://docs.djangoproject.com/en/6.0/ref/csrf/#why-might-a-user-encounter-a-csrf-validation-failure-after-logging-in), [получение актуального токена](https://docs.djangoproject.com/en/6.0/howto/csrf/).
- Мобильные фильтры: закрытая панель inert, открытая имеет семантику dialog и удерживает Tab; Escape сначала закрывает список, затем панель; фокус возвращается на кнопку. На desktop снимается блокировка прокрутки. Исправлен фактически неработавший ArrowDown: опции div получили tabindex, а CSS больше не анимирует их visibility.
