## №48. Сроки модерации

Владелец продукта подтвердил **72 календарных часа для места и 24 для отзыва**. Предупреждение начинается при 50% срока, критическое состояние — при 80%, просрочка — при 100%. Панель, сообщение автору и расчёт дедлайна получают значения из общей настройки. При отсутствии настроенного срока пользователь получает подтверждение приёма материала без обещания времени решения. [Продуктовый регламент](../product/moderation-sla-spec.md)

Исправлены пропуски в очереди и фильтрах. Модератор видит актуальную ожидающую редакцию отзыва, тогда как посетители продолжают видеть одобренный текст. Окончательный отказ по правке места попадает в «Отклонено», запрос исправлений — в «Нужна доработка». Исторические записи без полной истории версий сохраняют дату подачи с пометкой о приблизительном значении, когда точная дата отсутствует. Для импортированного отзыва учитывается исправленная дата исходной записи.

В сценарии с подачей в **00:30 по Баку** заявка видна в фильтре за соответствующий местный день. При переходе по счётчикам сохраняются остальные фильтры. Проверено отображение нестандартных тестовых сроков 36 и 12 часов. Эти значения использовались только в изолированном тесте.

## Похожие и ближайшие места

Сначала определяется действующая точка места по тем же правилам, что для карты. Затем база сравнивает все публичные места с допустимыми координатами и выбирает до шести. Сохранилось предпочтение своей категории, эквивалентное 1,5 км при выборе порядка. Посетителю показывается фактическое расстояние. Если подтверждён только адрес без точки, показывается блок «Другие места той же категории» без километров.

Исходный сценарий включал **2 001 кандидата**. Ближайшего соседа в 56 метрах вытесняли более новые записи за 293 км. Дополнительно проверены смена подтверждённого адреса, координаты только у подтверждённой площадки, архивированная точка, карточки без координат, недоступные места и переходы по выданным ссылкам.

Предшествующие результаты по остальным карточкам, в том числе сверка семи опубликованных парковых номеров, сохранены в двух отчётах. [Первичная проверка колонки](2026-11-21-clickup-review-verification.md) · [Проверка парков](2026-11-21-task-73-park-contacts.md)
