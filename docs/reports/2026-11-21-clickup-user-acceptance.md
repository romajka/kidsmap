## Как повторить

Срез с 14 карточками получен в ClickUp по статусу и ID списка `1100350000009588`. Личный браузер показал то же число. При загрузке всех полных описаний коннектор достиг дневного лимита. Для оставшихся подробностей использованы условия из ранее сверенных карточек и проектных отчётов. У основного исполнителя Codebase Memory вернул ошибку транспорта. В дополнительной сессии граф открылся, критичные выводы сверены с исходным кодом и исполнением.

**806 серверных тестов PostgreSQL** прошли. Три исходных группы — 115, 253 и 240. Расширение по направлениям — 115 и 17, по контактам, организациям, готовности и четырём тестовым записям — ещё 66. Перенос и восстановление проверены на Linux с Unix-сокетом PostgreSQL. Ожидаемые искусственные сбои внутри тестов завершились корректным откатом. Ещё три сквозных сценария видимости организаций и один сценарий выдачи и отзыва права официального ответа прошли на изолированной SQLite. В 36 проверках Node.js успешно прошли 34, ещё две потребовали работающий локальный браузерный стенд и затем отдельно прошли на нём.
