## Исправления после общего прогона

В RU-каталоге исправлены два fuzzy-перевода: «Черновик» и «Сохранить черновик». Ранее lookup мог использовать неверную подпись/азербайджанский fallback. Два существующих теста admin layout, выявившие проблему, теперь проходят.

Две устаревшие проверки приведены к явно изменённому продукту: PlaceReview хранит отдельные записи одного автора, SiteReview сохраняет уникальность; новая шапка проверяется по доступности аккаунта и всех трёх языков, а не пути старого изображения и классу прежнего дизайна. Проверки не заменены заглушками: сохранность первого отзыва/разные PK и прежняя SiteReview constraint проверяются отдельно, cooldown закрыт своим suite.

Повтор на PostgreSQL: эти два admin layout tests, PostgreSqlUniquenessTests, новый header contract и PlaceReviewCooldownTests — **18/18 OK, 17.603 s**. Остальные несовпадения полного suite не исправлялись ради green. Среди них старые markup/locale ожидания admin/public/phone/map и сброс cache/language в parallel test runner. Полный suite после этих точечных исправлений повторно не запускался.

Серверный OAuth-патч сверён с main и сохранён в Git stash и защищённом архиве. До миграций создан server-only PostgreSQL custom-format dump; `pg_restore --list` успешен (это не полный restore drill). Сохранены старый image tag, env и diff в `/root/kidsmap-releases/20260907-full-release/`; секреты и dump не копировались в Git/локальные отчёты.

Миграции 0102/0103 добавляют редакции и cooldown; 0103 снимает уникальность place/user у отзывов. Откат 0103 после появления повторных отзывов требует отдельного решения о сохранении истории — слепой reverse migration не безопасен. Старая версия образа сохраняется, но сама по себе не гарантирует schema rollback.

Static собирается без `--clear`: старые hashed assets остаются для уже открытых страниц. Компиляция переводов выполняется внутри образа. Внешний OAuth sign-in, полный penetration test и конфиденциальность общего `/media/` не сертифицированы этим релизом. Известное ограничение прямых media URL описано в `VOLUNTEER_WORKSPACE_AUDIT_AND_UX.md`.

Runtime-результат применения и проверки HTTP/ролей фиксируется в итоговом ответе и защищённом серверном каталоге релиза; этот документ подготовлен до переключения.
