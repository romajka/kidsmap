# Примечания к ценам старых карточек

Дата: 2026-09-13. Выполнено основным агентом, без независимых специалистов.
Область: локальный WORKTREE поверх c9697bae. Production в рамках этого исправления не изменялся.

## Источник проблемы

Публичный шаблон выводил `Place.extra_conditions_i18n` и `Place.additional_info_i18n`. Для RU эти методы используют старые `extra_conditions` / `additional_info`, когда соответствующий RU-перевод пуст. AZ и EN не используют этот fallback. Поэтому проблема особенно заметна на старых карточках.

Локализованные поля были в разделе «Локация», а дополнительная информация ошибочно называлась служебной. Старые поля отсутствовали в форме. Предупреждение о ценах являлось переводимой строкой шаблона и появлялось при наличии цены или тарифов.

## Исправление

- Примечания перенесены в «Цена и возраст», рядом с тарифами, и явно обозначены как публичные.
- Добавлен раздел «Текст старой карточки (RU)», автоматически раскрытый при наличии старых данных. Есть объяснение приоритета перевода и способа полной очистки.
- Старые поля включены в общий черновик Volunteer/Admin. Старые снимки совместимы с новым набором полей; первая запись фиксирует базовые значения. Сохраняются проверки конфликтов и аудит фактического старого/нового текста.
- Публичная версия остаётся неизменной до одобрения черновика.
- Переносы строк сохранены; HTML экранируется.
- Дисклеймер остаётся автоматическим переводимым текстом. Он показывается при наличии цен/тарифов у карточки без статуса «Проверено». Владение карточкой само по себе его не скрывает. В форме объяснено, что проверка должна включать цены.
- Текстовые поля уменьшены до четырёх строк с возможностью ручного растягивания.
- Для основной формы Place исправлен выбор языка AZ. Новые пояснения переведены на AZ/RU/EN; активированы два проверенных AZ-перевода старых подписей.

## Проверка

Изолированные Django-тесты запускаются с `DJANGO_TESTING=1`, локальным тестовым SQLite, тестовыми cache/media.

Команда: `.venv/Scripts/python.exe manage.py test catalog.testcases.test_legacy_pricing_notes catalog.testcases.test_volunteer_admin catalog.testcases.pricing_plans catalog.testcases.admin.TestAdminOwnershipModerationUX --verbosity 0`.

Итог полного запуска: 148 тестов за 221,834 с, 147 прошли, один пропущен (конкурентная проверка требует PostgreSQL), ошибок нет. Дополнительный регрессионный тест AZ воспроизвёл ошибку `ru != az` и прошёл после исправления.

`manage.py check`, `manage.py makemigrations --check --dry-run` и `git diff --check` проходят; новых миграций нет.

Firefox, отдельная синтетическая SQLite-база: основная админ-форма AZ/RU/EN при 1366 px; публичная RU при 1366 px, AZ/EN при 390 px. Проверены снимки, тексты и размеры DOM: scrollWidth равен ширине окна. Новые поля и пояснения читаются без горизонтального скролла. На заключительной странице консоль: 0 ошибок и предупреждений. Артефакты находятся в `output/playwright/pricing-notes-*.png`. Тестовый браузер и локальный сервер остановлены.

## Ограничения

Тексты реальной карточки №21 не переписывались. Смешанный AZ/RU-текст, уже сохранённый в старом поле, нужно разнести по языковым полям вручную. Исправление предоставляет инструменты для этого.

Статус «Проверено» относится ко всей карточке; отдельной модели подтверждения цены не добавлено. В общей админке вне изменённых контролов сохраняются прежние неполные переводы. PostgreSQL-конкурентность и production после этого изменения не проверялись. Push/deploy этого исправления не выполнялся.
